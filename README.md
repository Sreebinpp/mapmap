# India tiger and elephant corridors

Interactive map of India's tiger reserves, elephant reserves and the corridors between them, with Nepal and Bhutan parks, lion areas, species sites and the Panna landscape corridors.

Live site: https://sreebinpp.github.io/mapmap/

Open `index.html` through a web server (or GitHub Pages); the forest (`ft/`) and road/rail (`infra/`) layers load as separate files.
